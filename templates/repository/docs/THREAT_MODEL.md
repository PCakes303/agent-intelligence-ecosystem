# Threat Model

**Status:** template; complete before implementation handles untrusted input or sensitive data.

## Assets
List credentials, data, code, identities, policy decisions, audit records, and availability needs.

## Trust boundaries
Diagram users, agents, tools, plugins, network peers, build systems, storage, and external sources. Identify every crossing.

## Adversaries and abuse cases
Consider malicious users, compromised agents, poisoned dependencies, prompt injection, replay, privilege escalation, data exfiltration, denial of service, and insider error.

## Controls
For each threat, specify prevention, detection, response, owner, and verification test.

## Residual risk
Record accepted risks, assumptions, expiry/review date, and approver. Do not mark this template complete without a reviewed threat model.
