# Contributing

Contributions may improve schemas, validators, control mappings, source monitoring and synthetic tests. Legal interpretation and applicability decisions require qualified counsel and an identified organizational owner.

## Development

- Python 3.10+
- Install: python -m pip install -r requirements-dev.txt
- Validate: python -m compliance_governance.validate_registry
- Test: python -m unittest discover -s tests -v

Changes to legal status, effective dates, court orders, control obligations or applicability criteria require authoritative source links, a last-verified date, a next-review date and explicit uncertainty notes. Do not silently overwrite legal history.

Never add real personal data, confidential legal advice, privileged material or fabricated evidence.
