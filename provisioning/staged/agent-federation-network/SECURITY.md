# Security Policy

This is a local peer-policy contract scaffold, not a federation service.

Do not publish exploitable vulnerability details, credentials, personal data, or sensitive operational information in public issues. Use GitHub private vulnerability reporting or a private advisory only if enabled. No dedicated private reporting address is published in this packet; configure an approved private channel before production use.

Peer declarations are untrusted. This code does not authenticate peers, verify cryptographic signatures, enforce remote policy, propagate emergency stops, or isolate workloads. Do not connect production networks or exchange credentials based on this scaffold.
