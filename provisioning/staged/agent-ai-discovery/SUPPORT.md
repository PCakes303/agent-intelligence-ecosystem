# Support

- **Documentation and scope:** start with README.md and ROADMAP.md.
- **Defects and feature requests:** use GitHub Issues, including a minimal reproduction where appropriate.
- **Security concerns:** follow SECURITY.md; do not post sensitive details publicly.
- **Cross-repository questions:** consult the master ecosystem registry and dependency graph.

Please include repository revision, environment, expected behavior, actual behavior, and relevant sanitized logs when reporting a defect.
